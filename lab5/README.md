# Memory Match

A plain HTML/CSS/JavaScript memory game. No build step or dependencies.

**Run it:** open `index.html` in any modern browser.

**Host it free:** push this folder to a GitHub repo, then Settings → Pages → deploy from the `main` branch root.

Features: Easy (4×4), Medium (5×4), Hard (6×4); six emoji card themes; moves, timer, pairs and per-difficulty personal bests; 1–3 star rating; pause/resume; restart confirmation; light/dark theme; sound with mute; responsive layout (the grid turns portrait on narrow phones).

Star thresholds and the mismatch delay are at the top of `js/game.js`.
