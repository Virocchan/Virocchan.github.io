# Homestay Vsla website

Static website (HTML, CSS, JavaScript). Open `index.html` in a browser to preview.

## Structure
```
index.html              Page 1: Home (designed)
the-house.html          Page 2: The House (outline only)
gallery.html            Page 3: Gallery & Facilities (outline only)
explore-langkawi.html   Page 4: Explore Langkawi (outline only)
book.html               Page 5: Book (outline only)
about-contact.html      Page 6: About & Contact (outline only)
css/style.css           All styles (colors and fonts are variables at the top)
js/main.js              Shared motion: header, scroll reveal, count-up, hero parallax
js/booking-bar.js       Home booking bar (dates and guests, no price shown)
images/                 Home page photos
```
